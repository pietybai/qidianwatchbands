How to choose

Start from the case, then the material

The case decides the interface: a standard lug width takes any 16–24 mm band, while a moulded smartwatch or tracker connector has to be tooled for that model. The material then decides the tooling cost, the finish, and how the band behaves in wear — silicone for colour range and comfort, nylon for abrasion resistance, ceramic and steel for weight and a jewellery look.

If you are not sure which group fits, send the case model or the lug width and we will point you at the programme that already has tooling, which is usually the difference between a tooling charge and none.
